{{ _("PCからスマホへファイルを送る手順") }}

{{ _("PCで作業しているファイルをスマートフォンへ送る手順は、マウスのドラッグ操作とスキャンだけで完了します。") }}

  1. {{ _("ファイルをアップロードする：") }} {{ _("PCのブラウザでFS!QRのトップページを開き、送りたいファイルをドラッグ＆ドロップします。") }}
  2. {{ _("設定を調整する（任意）：") }} {{ _("必要に応じて、保持期間（例：1時間、1日など）の変更や、ID・パスワードによる保護設定を行います。") }}
  3. {{ _("QRコードを表示して読み取る：") }} {{ _("アップロード完了後に画面へ表示されるQRコードを、スマートフォンのカメラで読み取ります。") }}
  4. {{ _("スマホでダウンロード：") }} {{ _("スマートフォン側のブラウザで開いたページからダウンロードを実行し、保存します。") }}

{{ _("この方法なら、スマートフォン側にメールアドレスを設定していなかったり、チャットツールのアカウントが繋がっていなかったりする他人のスマートフォンに対しても、目の前に相手がいれば即座にファイルを渡すことができます。") }}

{{ _("スマホからPCへファイルを送る手順") }}

{{ _("スマートフォンで撮影した写真や保存したPDFデータをPCへ送る場合も、FS!QRの柔軟なインターフェースによって簡単に行えます。") }}

  1. {{ _("スマホでアップロード：") }} {{ _("スマートフォンのブラウザでFS!QRにアクセスし、ファイル選択画面からカメラロールやファイルアプリ内のデータを指定してアップロードします。") }}
  2. {{ _("PCで受け取る（QRコードの場合）：") }} {{ _("PCにQRコードを読み取れるカメラ環境がある場合は、スマートフォンのアップロード完了画面に表示されたQRコードを読み取り、ダウンロードページを開きます。") }}
  3. {{ _("PCで受け取る（リンク入力の場合）：") }} {{ _("PCにカメラがない場合や読み取りづらい場合は、スマートフォンのアップロード完了画面に表示される共有リンクをPCのブラウザに入力します。共有IDと6桁のパスワードを控えておくと、検索ページからもファイルを開けます。") }}
