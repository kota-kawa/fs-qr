# ADR-0009: HTML プレビューをブラウザ内で完結させる

## 状態

採用。

## 背景

第5のサービスでは、利用者が貼り付けた HTML を PC・スマホで Web ページとして確認します。
入力内容をサーバーに保存せず、表示処理もブラウザ内で完結させる必要があります。

## 判断

- `/html-preview` は画面と描画用の静的アセットを配信します。入力 API、ルーム、
  DB、Redis の保存領域を追加しません。
- 入力はタブ内のメモリにのみ置き、ストレージ、URL、ログに書き込みません。解析・広告タグも
  読み込まず、専用 CSP で入力 API への接続とフォーム送信を禁止します。
- 入力 HTML を inert な template で解析し、許可した HTML 要素と表示属性だけを再構築します。
  プレビューは `allow-scripts` のみを持つ sandbox iframe の srcdoc で表示し、同一オリジン権限は
  与えません。入力の script やイベント属性を除去し、サービス自身の描画処理を CSP nonce で許可します。
- CDN は Bootstrap 5.3.8 / Font Awesome 7.3.0 の CSS と、Mermaid 12.2.0 に限定します。
  固定 URL と SRI をサーバーの設定表で管理し、入力された link が一致する CSS と Mermaid 要素が
  存在する場合にだけ取得します。CSS 用フォントは同じ固定バージョンのパスに限定します。
  CSS はブラウザの fetch integrity で検証してから埋め込み、外部 style-src は許可しません。
  入力の `@import` による SRI 回避を遮断します。
- Mermaid は公式の `strict` 設定で描画し、安全性の設定を入力の図で上書きできないようにします。
  ライブラリの取得・整合性検証・描画の失敗は status で通知します。
- iframe 内の CSP で許可以外の外部通信と API 接続を拒否します。埋め込み CSS と data URL の
  ラスター画像も許可し、任意の JavaScript、外部画像、リンク移動、フォーム送信は無効化します。
- 共通ルーム画面のスクリプトを必要としないため、専用の軽量な HTML shell を使います。

## 理由

ルーム・保存・共有を追加せず、利用者が入力した内容を端末内だけで確認できます。
単なる script 除去では CSS や画像から外部通信が発生するため、要素・属性の制限、sandbox、
CSP を併用します。inert な template を使い、解析中の外部画像取得も避けます。
利用者が HTML のレイアウトや図を確認できるよう、必要な CDN を固定 URL と整合性検証付きで
許可します。全 CDN や任意 JavaScript の実行を許可する必要はありません。

## 影響

初回の画面と静的アセットの読み込みにはサーバー接続が必要です。CDN を使わない表示は接続不要で、
再読み込み時に入力は消えます。既存の共有4サービスの保存・認証・状態遷移は変更しません。
CDN 機能にはインターネット接続が必要で、CDN に IP アドレスとリソースの URL が届きます。
Referrer を送らず、HTML 本文を自サービスに送信・保存しません。
許可以外の外部リソースやスクリプトに依存するページの完全再現は対象外です。プレビューには基本の余白や
折り返しを補い、入力 CSS の固定幅指定まで自動的にレスポンシブ化することはしません。
Mermaid は既存ライブラリで代替できない図の描画のために追加する CDN 依存です。バージョンと
SRI は上記の設定表を正とし、無関係な Hocuspocus の package に追加しません。
環境変数、DB マイグレーション、Python 依存の追加は不要です。
